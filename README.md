# Notas Escena · código 0.2.1

Copia pública de solo lectura para revisar el proyecto. Contiene código de frontend, servidor, puente Telegram, pruebas y configuración de ejemplo. No contiene credenciales, sesiones de Telegram, datos personales, registros de autorización, estado de ejecución ni historial privado de Git. Los controles de autorización se conservan intactos.

## Proyecto descargable

[Descargar el proyecto en ZIP](notas-escena-source-0.2.1.zip). Descomprime para obtener las carpetas originales. Esta copia no concede acceso a la instalación publicada, a Telegram ni a Netlify.
