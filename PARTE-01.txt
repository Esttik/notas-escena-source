# Notas · Escena

PWA privada de notas para iPhone, con artista autenticado y consultas autorizadas. El flujo completo funciona con fichas ficticias: prepara una sesión, crea una nota y escribe `600 000-001`. Tras una pausa de 800 ms comienza la consulta automáticamente. La respuesta se reserva en memoria y aparece como vista temporal bajo el texto solo mientras mantienes pulsados los eslabones. Al soltar se oculta; nunca modifica el contenido ni el historial de la nota.

La integración real con @TrueCalleRobot se comprobó con el teléfono propio del titular mediante una sesión nueva de su cuenta de Telegram. El transporte entre bots sigue rechazado por Telegram; es una alternativa distinta. El [puente de cliente de usuario](bridge/README.md) no extrae sesiones existentes ni utiliza el servidor de Numeria. [Acta de comprobaciones](docs/ACTIVACION-TELEGRAM.md).

El proveedor de Netlify está activo en https://your-notes-project.netlify.app/lookup y conserva las credenciales exclusivamente en Functions de producción. Una consulta real obtuvo respuesta correlacionada en 2100 ms con el puente y el túnel locales apagados; la repetición del mismo UUID fue rechazada sin nuevo envío. La web privada mantiene su dirección de Sites. [Configuración Netlify](bridge/NETLIFY.md).

## Ejecución local

Necesitas Node.js 24, npm y un navegador. Las pruebas del bloqueo de nube necesitan PostgreSQL 17; `POSTGRES_BIN` permite indicar su carpeta bin. Se usa un clúster temporal aislado. Autenticación local simulada exclusivamente en loopback; no usar el servidor de desarrollo como hosting público.

```sh
cd /path/to/notas-escena
npm ci
npm run build
npm --prefix bridge ci --ignore-scripts
npm run test:bridge
npm run typecheck:bridge
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0000_bouncy_scalphunter.sql
node --import ./scripts/sites-env.mjs ./node_modules/wrangler/bin/wrangler.js d1 execute DB --local --config dist/server/wrangler.json --persist-to .wrangler/state --file drizzle/0001_robust_thunderball.sql
npm run dev -- --port 5176 --hostname 127.0.0.1
```

Aplica cada migración una sola vez por base local. Abre `http://127.0.0.1:5176/`; el inicio de sesión de desarrollo lo proporciona la plantilla Sites. Si preparas más de cinco sesiones en una hora, se aplica el límite del servidor; para ensayos automatizados usa la base local descartable de las pruebas.

No puede instalarse una PWA desde el localhost del ordenador en un iPhone remoto. Para usar un iPhone abre la dirección HTTPS publicada en Sites y autentícate con la cuenta propietaria.

## Uso

1. Menú superior de tres puntos → Área del artista.
2. Mantén seleccionadas las fichas ficticias y pulsa Preparar sesión.
3. Crea una nota con el botón de composición inferior.
4. Escribe `600000001`, `+34 600 000 001` o `0034-600-000-001` (Alba Ejemplo). La otra ficha sintética es `700000002` (Leo Ensayo).
5. Mantén pulsados los eslabones, a la derecha del lápiz circular: aparece el peek mientras sostienes el botón y se oculta al soltar. Si todavía está consultando, aparece al llegar solo si sigues manteniendo pulsado. Un toque breve no deja información visible. Puedes volver a mantener pulsado sin reenviar la consulta. En teclado, mantén Espacio o Intro sobre el botón.
6. Deshacer descarta el resultado reservado conservando el texto escrito. Borrar sesión y resultados elimina los metadatos del servidor y las notas de actuación en memoria.

Esos números son claves sintéticas: no se afirma que estén reservados ni que no correspondan a un abonado. El proveedor demo jamás los transmite fuera del servidor.

El teléfono debe ser el único contenido numérico de la nota. Se admite texto descriptivo en otras líneas; fechas, extensiones, dos números y formatos ambiguos se rechazan. No se escoge un número silenciosamente. El texto escrito permanece intacto.

La detección automática funciona solo con una sesión preparada y una ficha seleccionada. Cambiar el texto, la nota o la sesión invalida la respuesta pendiente o reservada. No se repite automáticamente la misma sesión/nota/número, ni tras un fallo o deshacer; mantener pulsado cuando falta un resultado inicia una consulta explícita. El peek puede verlo quien mire la pantalla mientras mantienes pulsado.

Las notas ordinarias se guardan en este dispositivo. Durante una actuación, abrir una nota ordinaria crea una copia temporal para proteger el original. Al cerrar o recargar se pierden los resultados y las notas de actuación. No hay sincronización de notas entre dispositivos.

## Arquitectura y decisiones

- TypeScript, React y Vinext; frontend de notas separado del servicio de sesión y del proveedor. Despliegue privado en Sites, identidad de ChatGPT gestionada por la plataforma; simulación de autenticación SOLO en desarrollo local.

- Editor contenteditable de texto plano y primera línea destacada. Selección y entrada nativas; historial de deshacer acotado y por nota para evitar diferencias de agrupación entre navegadores. Barra ajustada a VisualViewport y safe areas, sin teclado ni estado de sistema falsos.
- Sesión de dos horas, lista cerrada de participantes, una consulta pendiente por sesión, diez consultas por sesión y veinte por artista/hora. Por petición posterior del usuario (12/10/2026), detectar un único móvil autorizado inicia la consulta tras 800 ms sin cambios, incluso antes de pulsar los eslabones. No se consulta por cada pulsación; incompletos, ambiguos y fichas no seleccionadas no inician solicitudes. Sin reintentos automáticos del proveedor.
- La respuesta válida se reserva únicamente en memoria con su contexto exacto y el estado «recibido». Por petición posterior del usuario, mantener pulsados los eslabones la muestra temporalmente sin modificar el texto ni el historial de la nota; soltar, cancelar el gesto o dejar de ver la app la oculta. Se puede repetir sin consultar nuevamente; una edición, cambio de nota o sesión la descarta. Este flujo sustituye la consulta exclusivamente al pulsar del contrato inicial.
- Identificadores UUID, hash de revisión, número normalizado y sesión vinculan cada petición. Toda edición/cambio de nota/reinicio invalida la visualización pendiente. Respuestas como texto literal, nunca HTML.

El transporte directo está implementado, pero permanece desactivado hasta configurar token, ID numérico del destino, permisos y protocolo de respuesta confirmado. D1 serializa globalmente por bot; las respuestas requieren origen/conversación fijos, reply al mensaje enviado, teléfono coincidente y marcador final. No hay webhooks de entrada.
- El 12/10/2026 el usuario pidió explícitamente el enfoque de cuenta de usuario que sugiere Numeria, sustituyendo su prohibición inicial de automatizar la cuenta. Se añade un proceso Node MTProto propio, detrás del adaptador HTTP, con autenticación nueva autorizada, sesión cifrada, teléfono de getMe, destino fijo, ledger SQLite durable y sin reintentos. Es un proyecto Node con dependencias y tipos separados del Worker. No se extrae una sesión de Telegram Web/móvil. [Contrato del puente](bridge/SPEC.md). Se ha vinculado la cuenta y comprobado envío/recepción del teléfono propio; el proveedor se ejecuta en Netlify Functions con Postgres compartido, comprobado con el puente y túnel del Mac apagados. ===== ARCHIVO: app/api/[...path]/route.ts =====
import { env } from "cloudflare:workers";
import { getChatGPTUser } from "../../chatgpt-auth";
import { Service } from "../../../lib/server/service";
import { Store } from "../../../lib/server/store";
import {
  participants,
  isProviderConfigured,
  type ProviderConfig,
} from "../../../lib/server/providers";
import { AppError } from "../../../lib/domain";
import { TelegramProvider } from "../../../lib/server/telegram";
export const dynamic = "force-dynamic";
const headers = {
  "Content-Type": "application/json; charset=utf-8",
  "Cache-Control": "no-store, private",
  Vary: "Cookie",
  "X-Content-Type-Options": "nosniff",
};
async function handle(request: Request) {
  try {
    const user = await getChatGPTUser();
    if (!user) throw new AppError("AUTH", "Inicia sesión como artista.", 401);
    const config = env as unknown as ProviderConfig;
    const url = new URL(request.url),
      path = url.pathname;
    if (request.method === "GET" && path === "/api/config")
      return Response.json(
        {
          mode: config.PROVIDER_MODE ?? "demo",
          transport:
            config.PROVIDER_MODE === "real"
              ? (config.PROVIDER_TRANSPORT ?? "http")
              : "demo",
          artist: user.displayName,
          artistId: user.userId,
          participants: participants(config, user.userId),
          realConfigured: isProviderConfigured(
            config,
            env.DB ? new Store(env.DB) : undefined,
          ),
        },
        { headers },
      );
    if (!env.DB)
      throw new AppError(
        "DATABASE",
        "La base de sesiones no está disponible.",
        503,
      );
    const service = new Service(new Store(env.DB), config);
    if (request.method === "GET" && path === "/api/provider-check") {
      if (!(service.provider instanceof TelegramProvider))
        throw new AppError(
          "PROVIDER_CONFIG",
          "No hay transporte Telegram configurado.",
          409,
        );
      await service.rate(user.userId, "provider-check", 5);
      return Response.json(
        await service.provider.check(AbortSignal.timeout(8000)),
        { headers },
      );
    }
    if (request.method === "GET" && path === "/api/diagnostics")
      return Response.json(
        await service.diagnostics(
          user.userId,
          url.searchParams.get("sessionId") ?? "",
          request.headers.get("x-csrf-token"),
        ),
        { headers },
      );
    if (request.method !== "POST")
      throw new AppError("METHOD", "Ruta no disponible.", 404);
    if (
      request.headers.get("origin") !== url.origin ||
      request.headers.get("sec-fetch-site") === "cross-site"
    )
      throw new AppError("ORIGIN", "Origen no permitido.", 403);
    if (!request.headers.get("content-type")?.startsWith("application/json"))
      throw new AppError("CONTENT_TYPE", "Usa JSON.", 415);
    if (Number(request.headers.get("content-length")) > 32768)
      throw new AppError("TOO_LARGE", "Petición demasiado grande.", 413);
    // Stream limit before parsing, including requests without Content-Length.
    const reader = request.body?.getReader();
    if (!reader) throw new AppError("INPUT", "Falta cuerpo JSON.");
    let size = 0,
      content = "";
    const decoder = new TextDecoder();
    for (;;) {
      const { done, value } = await reader.read();
      if (done) break;
      size += value.byteLength;
      if (size > 32768) {
        await reader.cancel();
        throw new AppError("TOO_LARGE", "Petición demasiado grande.", 413);
      }
      content += decoder.decode(value, { stream: true });
    }
    content += decoder.decode();
    let body: Record<string, unknown>;
    try {
      body = JSON.parse(content);
    } catch {
      throw new AppError("INPUT", "JSON no válido.");
    }
    if (!body || typeof body !== "object" || Array.isArray(body))
      throw new AppError("INPUT", "Petición no válida.");
    if (path === "/api/session")
      return Response.json(await service.start(user.userId, body), { headers });
    if (path === "/api/erase") {
      await service.erase(user.userId);
      return Response.json({ ok: true }, { headers });
    }
    if (path === "/api/query")
      return Response.json(
        await service.query(
          user.userId,
          body,
          request.headers.get("x-csrf-token"),
        ),
        { headers },
      );
    throw new AppError("NOT_FOUND", "Ruta no disponible.", 404);
  } catch (error) {
    const e =
      error instanceof AppError
        ? error
        : new AppError(
            "INTERNAL",
            "Error interno. Vuelve a intentarlo desde el área del artista.",
            500,
          );
    // Log only a fixed error code. Never log exceptions from an external service.
    if (e.status >= 500) console.error(JSON.stringify({ code: e.code }));
    return Response.json(
      { error: e.message, code: e.code },
      { status: e.status, headers },
    );
  }
}

import { headers } from "next/headers";
import { redirect } from "next/navigation";

export type ChatGPTUser = {
  userId: string;
  displayName: string;
  email: string;
  fullName: string | null;
};

const USER_ID_HEADER = "oai-authenticated-user-id";
const USER_EMAIL_HEADER = "oai-authenticated-user-email";
const USER_FULL_NAME_HEADER = "oai-authenticated-user-full-name";
const USER_FULL_NAME_ENCODING_HEADER =
  "oai-authenticated-user-full-name-encoding";
const PERCENT_ENCODED_UTF8 = "percent-encoded-utf-8";
const SIGN_IN_PATH = "/signin-with-chatgpt";
const SIGN_OUT_PATH = "/signout-with-chatgpt";
const CALLBACK_PATH = "/callback";

export async function getChatGPTUser(): Promise<ChatGPTUser | null> {
  const requestHeaders = await headers();
  const userId = requestHeaders.get(USER_ID_HEADER);
  const email = requestHeaders.get(USER_EMAIL_HEADER);
  if (!userId || !email) return null;

  const encodedFullName = requestHeaders.get(USER_FULL_NAME_HEADER);
  const fullName =
    encodedFullName &&
    requestHeaders.get(USER_FULL_NAME_ENCODING_HEADER) === PERCENT_ENCODED_UTF8
      ? safeDecodeURIComponent(encodedFullName)
      : null;

  return {
    userId,
    displayName: fullName ?? email,
    email,
    fullName,
  };
}

export async function requireChatGPTUser(
  returnTo: string,
): Promise<ChatGPTUser> {
  const user = await getChatGPTUser();
  if (user) return user;

  redirect(chatGPTSignInPath(returnTo));
}

export function chatGPTSignInPath(returnTo: string): string {
  const safeReturnTo = safeRelativeReturnPath(returnTo);
  return `${SIGN_IN_PATH}?return_to=${encodeURIComponent(safeReturnTo)}`;
}

export function chatGPTSignOutPath(returnTo = "/"): string {
  const safeReturnTo = safeRelativeReturnPath(returnTo);
  return `${SIGN_OUT_PATH}?return_to=${encodeURIComponent(safeReturnTo)}`;
}

function safeRelativeReturnPath(value: string): string {
  if (!value.startsWith("/") || value.startsWith("//")) return "/";

  let url: URL;
  try {
    url = new URL(value, "https://app.local");
  } catch {
    return "/";
  }
  if (url.origin !== "https://app.local") return "/";
  if (isReservedAuthPath(url.pathname)) return "/";

  return `${url.pathname}${url.search}${url.hash}`;
}

function isReservedAuthPath(pathname: string): boolean {
  return (
    pathname === SIGN_IN_PATH ||
    pathname === SIGN_OUT_PATH ||
    pathname === CALLBACK_PATH
  );
}

function safeDecodeURIComponent(value: string): string | null {
  try {
    return decodeURIComponent(value);
  } catch {
    return null;
  }
}
